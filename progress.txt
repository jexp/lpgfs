## Task 008: Implement query: list nodes by label
- **Status:** Completed
- **PRD Reference:** Section 5.3 (Naming Strategy), Section 12.2 (Query Mapping)

### Key Decisions
- Created `getNodesByLabel(db, label, config)` function in src/db/queries.ts
- Uses Cypher: `MATCH (n:\`Label\`) RETURN elementId(n), properties(n)` (backticks escape label name)
- Returns `NodeQueryResult[]` with name, elementId, and properties
- Supports naming strategies: 'elementId' (default) or 'property' (via per-label override)
- Missing property falls back to sanitized elementId for robustness
- Integrates with `resolveCollisions()` for collision handling
- Added helper functions `getNamingStrategy()` and `getPropertyName()` for config lookup

### Files Changed
- src/db/queries.ts: Added getNodesByLabel() function with imports for types, sanitize, and collision modules

### Blockers/Notes
- None - typecheck passes

## Task 010: Implement query: list relationship types for node
- **Status:** Completed
- **PRD Reference:** Section 12.2 (Query Mapping)

### Key Decisions
- Created `getRelationshipTypes(db, label, name, config)` function in src/db/queries.ts
- Uses Cypher: `MATCH (n)-[r]-() WHERE elementId(n) = $elementId RETURN DISTINCT type(r) AS relType`
- Returns both outgoing and incoming relationship types (combined, as that's what the node dir needs)
- Returns string[] (empty array if node not found or has no relationships)
- Reuses `getNodesByLabel()` to find node by display name - ensures consistent naming logic
- Uses parameterized query with elementId for safety and performance

### Files Changed
- src/db/queries.ts: Added getRelationshipTypes() function

### Blockers/Notes
- None - typecheck passes
- Note: Uses same O(n) lookup pattern as getNodeProperties; caching (task-014) will optimize this

## Task 011: Implement query: list relationships by type & direction
- **Status:** Completed
- **PRD Reference:** Section 5.2 (Relationship Structure), Section 12.2 (Query Mapping)

### Key Decisions
- Created `getRelationships(db, label, name, relType, direction, config)` function in src/db/queries.ts
